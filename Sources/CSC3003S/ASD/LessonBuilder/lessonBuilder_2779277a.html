Welcome to Advanced Software Design

This part of the course is about software design, that is, how to turn ideas into quality effective and efficient code in a systematic and controlled manner.

We start by reviewing OOP & UML, project management and software development methodologies. We investigate software development with SCRUM. Software architecture is an important topic together with design patterns, security, and anti-pattern and we finally look into how software is tested and deployed.

INF2009F is a prerequisite for this course. Some of the key material from INF2009F, particularly on modelling and OOP, is included in the Week 0 materials as background reading. Please ensure that you have mastered this material for your Capstone Project.

The practical for this course is your Capstone Project. You will be expected to take the theory covered in lectures and apply them in your project. For more details, see the Capstone project overview.

Required Books:

  • Ian Sommerville “Software Engineering” (9th or 10th Edition) Addison-Wesley

Recommended Books:

  • Introduction to Systems Analysis and Design in a Changing World, 7th Edition by John W. Satzinger, Robert B. Jackson, Stephen D. Burd (from INF2009f)
  • Other texts will be referenced and made available throughout the course

This course will cover the following :

  • A recap of UML and OOP
  • Project management and software systems engineering
  • Software development methods and testing
  • Software process and quality
  • The use of generative AI in coding
  • Software Design: SOLID, Design patterns, and anti-patterns
  • System Architecture: MVC, Layered Architecture and Micro Services
  • Software Security
  • Services Oriented Architectures

Each week will include daily lectures and a quiz and activities. All material covered in the lectures and required readings are examinable. The quizzes will count towards your test mark for ASD.
