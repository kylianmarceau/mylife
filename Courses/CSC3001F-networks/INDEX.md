## Suggested Study Order

1. Start with [Introduction To Computer Networks](Lecture_Notes/Introduction.md) for vocabulary, layering, network structure, delay, loss, and throughput.
2. Study [Application Layer](Lecture_Notes/Application_Layer.md) before socket programming practical work.
3. Study [Transport Layer](Lecture_Notes/Transport_Layer.md) for reliability, TCP, flow control, and congestion control.
4. Study [Network Layer: Data Plane](Lecture_Notes/Network_Layer_Data_Plane.md) before [Network Layer: Control Plane](Lecture_Notes/Network_Layer_Control_Plane.md).
5. Study [Link Layer](Lecture_Notes/Link_Layer.md) after IP addressing so ARP, MAC addresses, and switches make sense.
6. Finish with [Network Security](Lecture_Notes/Network_Security.md), which builds on transport, application, and routing concepts.
