## Suggested Study Order

1. Start with [State Space Search](Search/01_State_Space_Search.md), then [Uninformed Search](Search/02_Uninformed_Search.md), because later search algorithms reuse their terminology.
2. Study [Depth-First Search And Iterative Deepening](Search/03_Depth_First_Search_And_Iterative_Deepening.md) before heuristic search so the time/space trade-off is clear.
3. Study [Heuristic Search, A*, And Beam Search](Search/04_Heuristic_Search_Astar_And_Beam.md) and [A* Memory Usage And Beam Search](Search/05_Astar_Memory_And_Beam_Search.md) together.
4. Move to game search: [Adversarial Search And Minimax](Search/06_Adversarial_Search_And_Minimax.md), [Multiplayer Minimax](Search/07_Multiplayer_Minimax.md), [Alpha-Beta Search](Search/08_Alpha_Beta_Search.md), [Evaluation Functions](Search/09_Evaluation_Functions.md), then [Monte Carlo Tree Search](Search/10_Monte_Carlo_Tree_Search.md).
5. Study the RL notes in order. The equations build from MDPs to value functions, then dynamic programming, model-free prediction/control, and finally deep/modern RL.
6. Study the Control notes after the RL foundations so PID, model-based control, and RL-based control can be compared directly.
