# Obsidian Study Vault

## How to use this vault

### Making notes from a source
1. Drop your source file (PDF, pptx, etc.) into the Sources/ folder
2. Tell Codex: "Read _agents/NOTES_AGENT.md and _skills/NOTE_TAKING_PHILOSOPHY.md, then make notes on [topic] from Sources/[filename]"
3. Codex will generate complete notes in `Courses/[SubjectName]/`
4. If multiple source files are provided, each source file must get its own note file unless you explicitly ask Codex to combine them.
5. Relevant source diagrams must be recreated as visually styled Mermaid and placed inside the content section where they belong, not collected at the end of the note.

### Making slides or a PDF from notes
1. Ensure notes already exist in `Courses/` (or provide a source directly)
2. Tell Codex: "Read _agents/SLIDE_AGENT.md and _skills/NOTE_TAKING_PHILOSOPHY.md, then make slides for [topic]"
3. Codex will generate a .pptx or .pdf in Slides/[SubjectName]/

### How to invoke agents correctly
Always start your request with:
"Read [agent file] and _skills/NOTE_TAKING_PHILOSOPHY.md first, then..."
This ensures Codex loads the philosophy and knows exactly what standard to meet before touching any source material.

### Adding a new subject
- Notes go in `Courses/[SubjectName]/`
- Slides go in `Slides/[SubjectName]/`
- Each subject folder will have an INDEX.md auto-generated by the Notes Agent

## File Map

| Path | Purpose |
|------|---------|
| _skills/NOTE_TAKING_PHILOSOPHY.md | Defines how all notes must be written — read this first always |
| _agents/NOTES_AGENT.md | Agent for generating markdown notes from source material |
| _agents/SLIDE_AGENT.md | Agent for generating pptx/pdf slide decks |
| Templates/NOTE_TEMPLATE.md | Base template used for all note files |
| Sources/ | Drop source files here before requesting notes |
| Courses/ | Generated notes in markdown, organised by subject |
| Slides/ | Generated slide decks organised by subject |
